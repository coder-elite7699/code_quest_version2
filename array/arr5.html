Contributer: Pradeep Kumar

Second Smallest Element in a given array

You are given an array containing integers. Your task is to return the second smallest element in the array

Example1:

arr = [78, 96, 14, 82, 35, 74, 6, 85, 2, 63, 64, 25]

output: 14

Explanation: The number 2 is smallest in array and 14 is second smallest

Example2:

arr = [45, 54, 62, 16, 25, 12, 65, 64, 52, 59, 44, 23]

output: 16

Explanation: 12 is smallest element in the given array and 16 is second smallest

Explanation

  • Take two variable, say mini and s_mini
  • Initialize each with maximum possible numbe, say INT_MAX
  • Iterate the array
  • If the element of array is smaller than mini, then store the value of mini in s_mini and update the mini
  • If number is not smaller than mini, check wether it is smaller tha s_mini and not equal to mini
  • If this is the case update the s_mini
  • return s_mini
