Right Rotate by one place

Your are given an array of integers. Your task is to return an array by roatating the array right by one place.

Example1:

arr = [1, 2, 3, 4, 5, 6, 7, 8, 9]

output:

[9, 1, 2, 3, 4, 5, 6, 7, 8]

Explanation: Since it is said the we have to roatate the array K place. The first element of the array is placed at right and all the shifted towards left by one place and this process is repeated three times

Example2:

arr = [1, 4, 11, 19, 25, 36, 39, 40, 42]

Output: [42, 1, 4, 11, 19, 25, 36, 39, 40]

Brute Force Appraoch

  • Take one variable
  • Store the last element of the array in that variable
  • Shift every element one place right
  • Put the last element at the 0 index

Optimal Appraoch

  • rotate the array from 0 to k-1 index
  • roatate the array from k to n-1 index
  • roatate the array from 0 to n-1 index
  • arr = [1,2,3,4,5,6,7,8,9]
  • given k=3
  • rotate(0, 2) => [3,2,1,4,5,6,7,8,9]
  • rotate(3, 8) => [3,2,1,9,8,7,6,5,4]
  • rotate(0, 8) => [4,5,6,7,8,9,1,2,3]
