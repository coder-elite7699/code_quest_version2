Contributer: Pradeep Kumar

Smallest Element in a given array

You are given an array containing integers. Your task is to return the smallest element in the array

Example1:

arr = [78, 96, 14, 82, 35, 74, 6, 85, 2, 63, 64, 25]

output: 2

Explanation: The number 2 is smallest in array

Example2:

arr = [45, 54, 62, 16, 25, 12, 65, 64, 52, 59, 44, 23]

output: 12

Explanation: 12 is smallest element in the given array

Explanation

  • Take a variable initializa it with INT_MAX say ans
  • INT_MAX is the maximum number
  • Start iterating the array
  • If number smaller than ans, update the ans variable
  • Once the iteration is complete , return the ans variable
