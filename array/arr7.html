Left Rotate by one place

Your are given an array of integers. Your task is to return an array by roatating the array left by one place

Example1:

arr = [1, 2, 3, 4, 5, 6, 7, 8, 9]

output:

[2, 3, 4, 5, 6, 7, 8, 9, 1]

Explanation: Since it is said the we have to roatate the array one place. The first element of the array is placed at right and all the shifted towards left by one place

Example2:

arr = [1, 4, 11, 19, 25, 36, 39, 40, 42]

Output: [4, 11, 19, 25, 36, 39, 40, 42, 1]

Explanation

  • Make a temporaray variable and store the first element of the array
  • Run a loop from 1 to N-1
  • Shift every element by one place: arr[i-1]=arr[i]
  • place the temporaray varaible value at last of the index
